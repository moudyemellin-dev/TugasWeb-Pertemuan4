# Tugas Rutin 4 - Konversi CSS ke SCSS

Tugas ini merupakan konversi CSS dari Pertemuan 2 ke SCSS menggunakan struktur modular 7-1 pattern.

## Teknologi

- HTML5
- CSS3
- SCSS / Sass
- Dart Sass
- Node.js
- npm

## Requirements yang Diterapkan

- Konversi CSS existing ke SCSS
- Variables untuk colors dan spacing
- Nesting maksimal 3 level
- Minimal 3 reusable mixins
- Struktur 7-1 pattern
- Menggunakan `@use`
- Menggunakan `@each`
- Compile menggunakan Dart Sass

## Struktur SCSS

- abstracts
- base
- components
- layout
- pages
- themes
- vendors
- main.scss

## Compile SCSS

```bash
npx sass scss/main.scss style.css
```
